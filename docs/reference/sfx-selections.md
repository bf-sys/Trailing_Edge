# SFX Selections

Hand-maintained — **not** regenerated by `tools/audio-triage/scan-kenney-audio.mjs`
(that only touches `docs/reference/sfx-sourcing-candidates.md`). Fill in
"Chosen file" as you go through the candidate pools in that doc against
each category from `docs/reference/sfx-asset-list.md`. Section numbers
match both of those docs for easy cross-reference.

**Chosen file** should be the exact path from the Kenney library root
(e.g. `Interface Sounds\Audio\click_003.ogg`), not a description — that's
the difference between a straight copy and a guess later. Leave blank for
anything you haven't decided yet or are skipping. Use **Notes** for
anything beyond a straight copy: trim silence, lower volume, pitch-shift,
"use variant 2 instead of the example shown," etc.
