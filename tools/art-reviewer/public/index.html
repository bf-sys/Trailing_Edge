How to use this tool

  1. Review the assets generated by the AI in the grid below.
  2. Toggle Composite View to see the assets keyed out over the parallax starfields.
  3. If an asset looks perfect, click Accept.
  4. If it needs changes, type your feedback in the text box (e.g., "Make it more red") and click Generate & Apply.
  5. The tool will directly contact the Gemini API and overwrite the asset seamlessly in a few seconds!
  6. Pro Tip: If an asset is being stubborn and won't follow your constraints, open server.js and change the model string from gemini-3.1-flash-image to gemini-3-pro-image for that run!
